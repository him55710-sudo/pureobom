# 설명 요청 분할 실험 · 미채택

2026-10-20, 실제 비공개 프로젝트의 고정 함수 과제를 개요와 사례별 요청으로 나눠 보았다. **전체 600초 안에 끝내지 못했고, 받은 답변에도 의미 오류가 남았다. 제품에 분할 요청 기능을 추가하지 않았다.**

## 방법

기존 [4B 과제](evidence/local-ai/arithmetic-model-followup.json)와 같은 전체 소스·함수·원래 질문·일곱 관측 사례·모델 digest를 사용했다. 로컬 CPU, `think:false`, 응답당 4096 출력 토큰으로 실행했다. 실험 클라이언트는 `16a338d`의 실제 Ollama 경로다.

개요 단계에는 관측 사례를 생략하고 역할·검사·호출자 전제를 설명하도록 추가 지시했다. 뒤의 일곱 단계에는 관측 사례를 하나씩 넣고 해당 결과의 근거를 짧게 설명하도록 추가 지시했다. 따라서 이전 일괄 요청과 **동일 메시지 비교가 아니다**. 모든 사례를 다룰 예정이었으며 처음부터 전체 실행에 600초 제한을 걸었다. 사례를 줄인 성공으로 평가하지 않는다.

기존 원문 인용·예시 연결 검증을 그대로 사용했다. 이전 native 대조의 반환 여섯 일치·한 개 확인 불가 관측을 재사용했으며, 새 애플리케이션 실행 검사로 세지 않는다. 원문·입력·실제 값·원시 모델 답변은 로컬에만 보존하고 내부 추론 텍스트는 저장 자료에서 제외했다.

[단계별 토큰·생성 시간·판정](evidence/local-ai/split-explanation-experiment.json). 평가자가 같은 개발 에이전트이고 한 과제의 한 번 실행이므로 독립 평가나 일반 정확도 비율이 아니다. 개요 문맥은 16384, 완료된 사례 문맥은 32768이었다. 프롬프트·출력 길이·캐시 조건이 다르고 UI 빌드·분석 작업도 일부 겹쳤으므로 단순 지연 비교나 속도 개선 효과를 주장하지 않는다.

## 결정

분할 방식은 이번 과제의 정확도·완성 시간 조건을 충족하지 못해 미채택이다. 처음 개요를 빨리 받는 것과 전체 과제를 정확히 끝내는 것을 구별한다. 이전 [추론 켜기 요청의 시간 초과](LOCAL_AI_THINKING.md)도 함께 유지하며, 로컬 실행·유료 API 호출 없음이 의미 정확성을 보장하지 않는다는 한계를 남긴다.

원문은 보존됐다. 전체 제한 후 서버의 요청 취소·유휴 상태를 확인했고, 전용 서버/runner의 경로와 부모 관계를 확인해 종료했다. 다른 프로젝트 서버에는 변경을 가하지 않았다.
